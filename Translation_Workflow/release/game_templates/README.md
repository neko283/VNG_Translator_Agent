# 游戏实施记录模板

复制本目录到 `<user_work_root>/release/<game_id>/`，将此标题和下表替换为实际信息。当前模板没有执行任何游戏处理。

| 项目 | 内容 |
| --- | --- |
| 游戏 ID | 与目录名一致，使用小写英文字母、数字和连字符 |
| 游戏名称 | 原名，待填写 |
| 实施目录 | 用户指定工作根目录下的 `release/<game_id>/`，填写绝对路径 |
| 原游戏路径 | 用户指定的游戏绝对路径；不放入工具目录 |
| 引擎及版本 | 待确认，附识别证据 |
| 游戏基线 | 发行版、更新状态、程序／资源哈希 |
| 翻译范围 | 仅对白和旁白；选项框、设置、菜单及图片文字保留原文 |
| 当前阶段 | 未实施 |
| 工作目录 | 本目录下 `work/`，实际开始时创建 |
| 工程／任务 ID | 待导入后记录；不能编造 |
| 下一步 | 识别资源与建立基线 |

- [实施方案](实施方案.md)
- [实施日志](实施日志.md)
- [结果与验收](结果与验收.md)
- [检查证据](evidence/README.md)
- 公共流程（工具包内 `Translation_Workflow/通用实施流程.md`）
