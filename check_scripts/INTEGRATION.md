# 整合与独立分发

本文描述技术上的整合和独立运行能力，不证明已取得上游修改或分发许可。LinguaGacha 来源、改动及截至 2026-11-04 的权限核对结论见 [项目 README](../README.md#上游使用与二次开发权限)。

## 保留内容

`LinguaGacha_Agent/` 保留 CLI、TypeScript 源码、必要上游源码闭包、内置保护规则、依赖锁文件、构建维护脚本、合成测试、共享技能和文档。`upstream/builtin/` 的 JSON 是运行规则，`docs/upstream-hashes.json` 是源码溯源清单，均不是历史翻译数据。来源见 [模块溯源说明](../LinguaGacha_Agent/docs/UPSTREAM.md)。

`Game_Engine_Tools/` 保留 PF8 Python 工具、Ruby 独立复核器、合成测试、工具用法和引擎适配说明。`Translation_Workflow/` 统一维护跨引擎通用的完整流程和空白实施模板。模板位于 `Translation_Workflow/release/game_templates/`，其中 `evidence/` 是检查证据目录；实际游戏实施记录统一放在工具包之外的 `<user_work_root>/release/<game_id>/`。目录使用英文，文档文件名保留中文。旧流程中翻译选项、在工具目录创建工作区的约定已按当前需求更新。

## 排除内容

不迁入真实游戏实施目录及其适配器、原始/解包资源、译文、术语实例、`.lg`、任务回执、字体、映射、历史记录、截图、检查报告、发布包、备份、虚拟环境、依赖目录、缓存及旧构建产物。

检查过的游戏专属适配器含固定游戏名、包名、机器路径、任务 ID、字体哈希、特定脚本语法或历史兼容数据，不能直接作为通用工具分发。因此不复制进本包；新游戏在用户工作目录实现适配，通用化并验证后才纳入工具层。原来源目录保留，未删除或改写。

## 独立性与前提

- 本地源码、资源、技能和文档链接均位于本目录内，无指向相邻工程的链接。
- Node.js、npm、Python 是声明的运行环境，npm 包由本地锁文件安装；Ruby 是可选复核环境。这些不是开发者工作区依赖。
- 游戏目录、工作目录及必要字体由使用者显式提供。示例和用户路径参数不代表内置资源依赖。
- 网络链接仅用于溯源和可选研究，核心 CLI 与 PF8 运行不访问上游站点。宿主模型的联网方式由用户所用 coding agent 决定。
- 包内历史实现说明描述翻译模块的开发验证范围，不代表新游戏的实机验收结果。

## 可重复验证

`npm run verify` 检查文档和路径边界、翻译模块类型与测试、构建输入闭包，以及 PF8 合成测试。需要先 `npm run setup`。

```sh
python3 check_scripts/verify-portable.py
```

隔离验证只复制干净源码到系统临时目录，排除依赖、旧构建和缓存，按锁文件重新安装、构建、检查并运行 doctor。临时目录不放相邻源码或游戏数据。安装可能需要网络，成功或失败都会清理本次临时目录。该验证不运行游戏，不代表已验证游戏字体、安装器或全路线。

## 本次整合验证（2026-11-03）

本次在 macOS、Node.js 24.22.1、Python 3.9 环境完成离线验证：将干净源码和本机已安装的依赖复制到独立临时目录，逐包核对 14 个已安装依赖版本与锁文件一致，并确认依赖符号链接未越出临时包。清除 `NODE_PATH` 和 `NODE_OPTIONS` 后运行 `npm run verify` 与 `npm run doctor`。

结果：翻译模块 23 项测试、PF8 合成测试 7 项全部通过；TypeScript 检查通过，94 个构建输入均在模块内部，包内本地文档链接有效，SQLite/zstd 与三种文本格式检查正常。最终源码目录没有依赖目录、构建输出、游戏数据或外部符号链接。

联网的全新 `npm ci` 因当前环境无法访问包仓库而未完成，本机下载缓存也不完整，因此不把本次离线验证记为全新联网安装验证。其他使用者首次下载仍需按 README 安装锁定依赖。Windows 实机与具体游戏补丁不在本次验证范围内。
